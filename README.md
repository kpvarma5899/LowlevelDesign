# LowlevelDesign

High-level and low-level design notes for interview prep. One folder per question.

**Read them:** https://kpvarma5899.github.io/LowlevelDesign/

| # | Question | Problem | Source |
|---|---|---|---|
| 1 | URL shortener | [questions/url-shortener](questions/url-shortener/README.md) | [src](questions/url-shortener/src) |
| 2 | Rate limiter | [questions/rate-limiter](questions/rate-limiter/README.md) | [src](questions/rate-limiter/src) |

Each question folder holds two things:

- `README.md` is the problem: the design you defend, and the link to its page.
- `src/` is the implementation: the source, and the design patterns that code uses.

The sentence each note closes on:

1. **URL shortener.** The short code is an obfuscated unique id, the database unique key is the real lock, and the redirect path never writes to the link row.
2. **Rate limiter.** Decide with one atomic check-and-consume on a shared counter, answer 429 with Retry-After, and keep a Redis timeout from taking down the API.

`docs/` is the site, generated by [`cache/canvas-to-pages.mjs`](cache/canvas-to-pages.mjs). Change a note, then run the renderer. Do not edit `docs/` by hand.
